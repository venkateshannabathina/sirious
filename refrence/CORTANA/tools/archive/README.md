# Archived diagnostics

These files are retained for historical reference and are not part of the CORTANA runtime or release artifact.

- `dump_pmx.js` and `parse_pmx_bones.js` were one-off PMX inspection experiments.
- `test_logs.js` was an early browser-console smoke script for the former port-8000 app.
- `test_retarget.html` was an early PMX-to-FBX retargeting experiment.

They intentionally remain unchanged so their original assumptions are visible. Current release checks live in `tests/` and `docs/qa-checklist.md`.
